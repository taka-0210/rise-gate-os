# 独立したTODOアプリ
RISE GATE OSのアカウントやAPIを使わず、PHPとSQLiteで動きます。
必要環境：PHP 8.2以降、PDO SQLite、mbstring、HTTPS（公開時）。
public/だけをWebの公開ディレクトリに指定してください。database.php、setup.php、data/は公開範囲の外です。
ローカルでは3ペインの「TODOのひな形」で管理者を設定し、「起動」を押します。
管理者でログインしてスタッフを追加します。パスワードはハッシュ化して保存します。

## 初回公開
公開用ZIPを展開し、サーバーのターミナルでプロジェクト直下の「php setup.php」を実行します。
管理者ID・パスワードを入力してください。端末の入力表示に注意してください。
SSHを使えないサーバーでは管理者にこの初期設定を依頼してください。
Webサーバーの公開ディレクトリをpublic/に設定し、PHP実行ユーザーがdata/を読み書きできるようにします。
ローカルのテスト用アカウント・TODOは公開用ZIPに含まれません。本番用アカウントを作成してください。
別端末からは同じ公開URLへログインすれば同じDBを利用できます。

## 更新
data/（DB・セッション）を消さず、プログラムを更新します。DBの変更が必要なら先にバックアップを取得します。
開発用データで本番のDBを上書きしないでください。すべての表示時刻はAsia/Tokyoです。
SQLiteをネットワーク共有やOneDriveで同期して複数端末から直接開く方式は使わず、公開サーバー経由でアクセスします。
