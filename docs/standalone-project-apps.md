# 3ペインから作る独立アプリ

作成・更新はCompany OSのプロジェクト編集権限を持つ人が行います。利用時はアプリ専用のアカウントでログインします。Company OSの会員登録やログインは不要です。

## 作成・利用

1. 3ペインのFILESにある「TODOのひな形から作成」を押します。
2. アプリ名、専用の管理者ログインID・パスワードを設定します。
3. 保存済みアプリの「別タブで開く」を押し、その管理者でログインします。
4. 「アカウント管理」でstaff1、staff2、staff3などのスタッフを追加します。
5. アプリの専用URLを利用者へ渡します。各自の端末から、アプリ専用ID・パスワードで利用できます。

管理者は画面上部で対象スタッフを選び、データを確認・編集できます。スタッフは自分のデータだけを扱えます。パスワードは8文字以上で設定し、サーバーにはハッシュを保存します。アカウントの停止やパスワード更新では、そのアカウントのアプリセッションを無効にします。

## AIで作成・変更

AIに「独立したログインを持つTODOアプリをサーバー保存で作って」と依頼できます。HTMLの回答にある「アプリとして登録」から登録してください。ローカルフォルダがなくても新規HTMLの生成・登録ができます。

既存のローカルHTMLは、FILESで開いて「アプリとして登録」を押します。ただし、登録だけではlocalStorageのコードはサーバー保存へ変わりません。先にAIへ「このアプリの認証を専用ログインに、保存をriseGateAppによるサーバー保存に変更して」と依頼してください。

保存済みアプリは「ソースを開く」からAIへ変更を依頼できます。更新時には登録先として同じアプリを選びます。アプリ名や画面のコードを変更しても、アプリIDとデータは引き継がれます。新しいアプリとして登録すると別の保存領域になります。

## 保存API

1ファイルのHTMLアプリにインラインCSS・JavaScriptを含めます。任意のPHP・SQL・外部バックエンドを生成・実行する機能ではありません。外部CDN・API・別iframeには依存せず、画像はdata URLを利用してください。

アプリにはホストから次のSDKが渡されます。

```js
const {data, user} = await window.riseGateApp.load();
const state = data ?? {todos: []};
await window.riseGateApp.save(state);
```

データはJSONオブジェクトまたは配列、1アカウント・1アプリにつき500KB以内です。アプリ本体は1MB以内です。SDKがデータの版を管理し、別端末の更新を古い画面で上書きしようとすると409エラーになります。読込失敗を初期データ扱いにせず、保存完了を待ってから成功を表示してください。保存に失敗した場合は再読込が必要です。

認証情報・CSRFトークンは生成HTMLに渡しません。生成コードは別オリジンのsandbox iframeで実行し、ホストはそのフレームからのload/saveだけをアプリ固有のAPIへ中継します。保存日時はJSTです。

## 既存データ

ブラウザに保存済みのデータは自動移行されません。元のアプリで対象ユーザーのTODOだけをJSONへ書き出してから取り込みます。ひな形の取込形式は次のとおりです。ログインID・パスワードは移行JSONに含めません。

```json
{"todos":[{"id":"todo-1","title":"見積書を送る","done":false}]}
```

同じidのTODOは重複追加しません。異なる形式はAIへ変換を依頼してください。端末を変えても同じサーバー上の同じアプリ・専用アカウントならデータを取得できます。別サーバーへ移設する際はデータベースとAPP_KEYなどの既存環境設定も保持してください。

## 運用・検証

テーブルはproject_apps、project_app_accounts、project_app_sessions、project_app_dataです。既存の手動本番デプロイはartisan migrateを実行します。Git pushでは本番反映されません。

- PHP: `php artisan test`
- JavaScript: `node tests/JavaScript/project-app-runtime.test.mjs`
- 既存ファイル保存: `node tests/JavaScript/ai-file-save.test.mjs`
- 実ブラウザ: `php -S 127.0.0.1:8766 tests/Browser/router.php` を起動し、`http://127.0.0.1:8766/tests/Browser/project-app-runtime.html` をChromeで開きます。PASS表示を確認します。このテストの保存先はメモリ上の模擬APIです。実DBとログインの分離はPHPテストで確認します。
